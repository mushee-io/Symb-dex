# Symb Dex official two-fish identity

The approved Symb Dex symbol is the **two fish swimming in opposite directions**, supplied as a white-on-black original logo on 25 October 2026. Do not substitute the previous star/arrow icon or the wordmark-only temporary brand.

## Usage
- `/brand/symb-fish.svg`: transparent white two-fish artwork vectorized from the supplied image. Use over a dark badge/background; keep its original wide proportion (320 × 212) and avoid distortion.
- `/icon.svg`: compact black rounded-square favicon derived from the same artwork.
- Navbar, exchange sidebar, homepage announcement, and product-card micro-branding all show the new two-fish symbol.
- Retain the wordmark **SYMB DEX** beside the mark for accessibility and recognition.

The public homepage keeps forest green/ivory; the exchange continues its slate/yellow design. This is a visual branding change only. It does not modify contracts, connected-wallet behaviour, chain IDs, the testnet readiness gate or mainnet release permissions.

The supplied original raster file remains with the user. The repository stores a **simplified SVG trace** suitable for small website placements; this is not a pixel-for-pixel copy of the full-resolution raster. Do not represent the trace as the original archival master.
