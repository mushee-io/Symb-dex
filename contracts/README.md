# Smart contracts — Milestone 2 (not deployed)

Milestone 1 is deliberately frontend, network validation and security gating only. No AMM is currently in this repo and no address is safe to send funds to.

The next milestone will add Foundry, a reviewed V2-style constant-product AMM implementation (factory, pair, router), LP accounting, invariant tests and reproducible verification scripts.

**Security:** no contracts should be deployed or connected to production wallet actions until reviewed and verified on VERY Mainnet.
