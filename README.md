# Lidde DEX

A non-custodial decentralized exchange in development for VERY Chain (EVM, chain ID 4613).

**Status:** Development only. No trading contracts are deployed by this repository, and the UI must not represent itself as a live exchange until independently verified contracts and liquidity are available.

Milestone implementation is tracked through pull requests. Official chain documentation: https://verylabs.io/whitepaper/en/developers/.
